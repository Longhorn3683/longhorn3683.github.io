前言

高中那时候买了个Gear S3故障机（传感器用不了），体验了Tizen系统和旋转表圈。Tizen给了我很多惊喜，就是应用生态真的不行，看小说的app都没有；旋转表圈挺好玩，音乐可以旋转切歌（现在改成了音量调节），表盘可以旋转切换卡片。还有一些依赖旋转表圈的游戏，例如Monster Vampire和Omnitrix（仿Ben 10手表玩法），前者因Tizen商店关闭已经下不到了（网上应该有安装包），换Wear OS后也没重制。

上大学一段时间后，我买下了基友的OPPO Watch 2。用了几个月，总感觉OPPO的系统差点意思。虽然O系手机能用流体云提醒，轻智能模式也非常省电，但AOD等于没有，且没有完善的表盘制作工具。而且全智能模式下反应很慢，应该是闪存寿命到头了（毕竟快5年了，还是高中重度使用）。于是我又把目光转回了三星。

一开始我考虑的是4C，海鲜市场也就100多（不愧是跳水之王）。和我用三星全家桶的同学聊了一下（S23 Ultra+Watch6 Classic+三星某Buds），他说三星就是一坨💩，打算卖了换其他家。于是我就把W6C顺来了，并把我的OW2给他玩一段时间😃

Tizen和Wear OS

三星手表最初以Gear命名，在Gear S3之后改名为Galaxy Watch。

三星Gear初代用的是安卓系统，Gear 2开始使用Tizen。Tizen系统流畅、续航好，但应用生态一直被人诟病，因此从Galaxy Watch4开始用上了三星深度定制的Wear OS by Google（基于安卓），解决了应用生态的问题。

由于Tizen的三星手表已经过时，且商店已经关闭，因此本教程以Wear OS的三星手表为主。

非三星劝退的点

三星手机配对三星手表还算简单，只要注意地区版本限制就行（国行配国行，外版配外版），就算出现地区版本问题也比较好解决。

但非三星手机配对三星手表就非常麻烦了，以下缺点就足够劝退很多人：

  • 同样有地区版本限制（国行的谷歌服务阉割，而Wear OS国内和国际版本来就不一样）
  • 要装很多APP，且一些APP没有官方的下载渠道（手表连接一个APP，健康一个APP，NFC一个APP，etc.）
  • 有断联的bug（重新配对需要重置，目前也没有完美不重置重新配对的方法，纯搞人心态）

不支持的功能包括但不限于：

  • 备份上传到三星云（明明Tizen还可以，换Wear OS居然砍了。。。）
  • 血压和心电图（One UI 8之前还能用修改版的三星健康监测器，8开始就只能用第三方了，还不好用）
  • 情景模式同步
  • 闹钟联动

安装APP汇总

必须安装

三星智能穿戴（Galaxy Wearable）

三星穿戴设备的入口，各家应用商店都有。

以下APP在配对时会自动下载：

各型号对应的Manager

手表的管理工具。

Wear OS by Google中国版

国行表需要此应用保持手表连接。

S换机助手（Smart Switch）

三星手机搬家工具，同样用于三星手表的备份。

可选安装

三星健康（Samsung Health）

查看心率、睡眠等数据。

健康服务

同步数据到微信运动、支付宝运动等平台的插件。

三星应用商店

方便在手机上管理手表的应用。

三星智能卡（Samsung NFC Card）

管理手表的公交卡、门禁卡、车钥匙。

Microsoft Edge

一些APP登录需要拉起浏览器，而三星的登录只支持部分浏览器。如果有支持的浏览器就不用下。

推荐安装的APP

WearOS工具箱（手机端）/安卓手表ADB实用工具箱（电脑端）

主要用来给手表安装非商店的APP和表盘。

一些想吐槽的点

要下一堆应用

别家基本都只用下一个APP，三星基本上各功能就要下各对应的APP，逆天了。

备份不支持手动，非三星手机不支持上传云

只能凌晨自动备份，而备份依赖S换机助手。

S换机助手开自启动和关联启动也没触发过一次备份。。。

Tizen还可以独立手动备份并上传到三星云，到了Wear OS就砍了。。。

重置可以触发备份，然而备份成功就直接重置了。。。

伞兵三星😓

非三星手机可能会断联，且需要重新配对

这bug万年没修了，只能通过一些方法避免：

  • 打开Manager和Wear OS的读取应用列表权限
  • 打开Manager、Wear OS、三星健康的自启动和关联启动
  • 不更改蓝牙名称

高斯模糊掉帧

4～6的W920/930太弱了，加上三星的垃圾优化，几乎100%掉帧。

设置->辅助功能->视觉增强->减少透明度和模糊效果，肉眼可见掉帧减少了很多。

7代的W1000提升了不少，理论上掉帧没那么严重了。

微信运动无法绑定

如果上家微信没解绑设备就会这样，只能让上家解绑。

血压和心电图不支持非三星手机

明明软件就能适配的功能，偏要绑自家手机，One UI 8还把三星健康监测器的修改版制裁了。。。
