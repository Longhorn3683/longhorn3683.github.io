IIDX HDD常见问题

本文最后更新于：2026年10月3日 下午

警告

本文仅用于学习用途，不提供任何HDD资源的下载。如果不想折腾HDD运行，请出门右转beatmania IIDX INFINITAS。

除了LDJ模式和老HDD相关内容，本文均以33代TDJ模式为准。

提出问题前请检查以下内容

  • spice2x 为最新版本
  • HDD数据完整
  • 已开启高性能/卓越性能模式
  • 笔记本用户确保
    • 已接入电源
    • 已开启独显直连（若有）

显示相关

官机使用显卡为NVIDIA GeForce GTX 1650，因此推荐使用1650及以上N卡。A卡和I卡也能用，就是跑HDD没N卡好用。

屏幕

官机主屏为43英寸，副屏为21/23英寸。尺寸可参考官机，分辨率达到以下要求即可。

  • 主屏：1920x1080 120Hz
  • 副屏：1280x720 60Hz

不建议使用非16:9比例屏幕。

一步到位就LG C系列42英寸电视？（非广）

MONITOR CHECK

IIDX是帧判定游戏，有良好的自检帧数才能有良好的判定，FPS在120左右浮动为正常。

FPS明显不在120左右/无法过MONITOR CHECK

桌面右键 -> 显示设置 -> 高级显示设置 -> 显示器属性 -> 列出所有模式，设置分辨率为1920x1080 120Hz，查看活动信号模式（也就是实际显示输出）是否为1920x1080 120Hz。

  • 没有1920x1080 120Hz的选项
    • 使用显卡控制面板设置自定义分辨率
  • 活动信号模式无法设置1920x1080 120Hz
    • 可尝试使用显卡控制面板设置
      • 设置分辨率和刷新率
      • 关闭GPU缩放
    • 内置屏幕无法设置活动信号模式
    • 显示器没有报告对应参数
      • 使用显卡控制面板设置自定义分辨率

FPS固定，完全没有浮动

关闭G-Sync或FreeSync。

每次启动都要执行多次MONITOR CHECK

官机的MONITOR CHECK FPS一般都是119.98XX，超出这范围就会重新CHECK，实在不想等可以尝试以下方法：

  • 使用CRU自定义分辨率
    • 把所有120Hz的分辨率删除并创建个119.98Hz的分辨率（小白切勿尝试）。
  • 使用patch（不推荐）
    • 使用patch会使FPS不准确造成判定漂移。
    • Run Monitor Check Once（仅运行一次CHECK）
    • Skip Monitor Check（跳过CHECK）

LDJ模式

游戏本身不怎么吃配置，但如果性能实在过低或显示器达不到要求，可考虑切换到LDJ模式。

LDJ模式需屏幕支持1920x1080 60Hz（可设置强制720P）。

  • 使用LDJ-012的bm2dx.dll
  • LDJ-010使用patch
    • Force LDJ Mode

A卡常见问题

如果资金充足还是建议换N卡，A卡对DX9支持一般。

MODE SELECT、打歌等界面掉帧

RDNA架构对DX9支持较差，把spicecfg的Option -> Display -> V-Sync Buffering设置为Triple（三重缓冲）可解决掉帧问题，但延迟也会变高。

用DXVK虽然也能解决，但物理副屏会无法显示，且延迟比DX9开三重缓冲还高。

9on12全屏会黑屏，且wiki里也说IIDX不支持9on12，因此这个方法不可用。

登录二维码无法正常显示

用DXVK可以解决，但物理副屏会无法显示。

这功能一般也用不上吧😂

音频相关

官机使用声卡为ASUS Xonar AE，大概几百一张，目前已经很难买到。

一般来说延迟：ASIO < WASAPI独占 < WASAPI共享

音频延迟高

  • 确保未启用Force Monitor Adjust Offset
  • 使用ASIO或WASAPI独占
  • 关闭各种音效
  • 不使用显卡的音频输出
  • 使用系统音频驱动（一些垃圾驱动甚至会吃key音🤣）
  • 使用ASIO4ALL（可能有点用？）

自带录屏相关

激活录屏功能有以下要求：

  • LDJ-010的bm2dx.dll（也就是新框的dll）
  • 10系及以上N卡（A卡有替代方案，I卡暂无解）
  • 录屏服务器可用

录屏黑屏

游戏自带的录屏功能依赖nvEncodeAPI64.dll，也就是N卡的dll。

  • N卡：支持10系及以上，确保游戏目录没有nvEncodeAPI64.dll
  • A卡：使用nvencoder-amf的nvEncodeAPI64.dll
  • I卡：暂时无解（不会有人用I卡跑HDD吧）

录屏服务器

一些服务器支持上传录像，如果不支持可使用本地服务器。

部分相关patch

不同服务器对录屏的规定不一样，请根据服务器的教程设置。

  • Disable Recording Lock
  • Disable Server Region Check for Premium Area Functions
  • Faster video uploads

副屏相关

spice2x支持按PageUp调出虚拟副屏，如果资金充足可以买个物理副屏，也可以使用其他方案。

物理副屏

需至少支持1280x720 60Hz。

IIDX的副屏触摸实际上是主屏触摸映射到游戏的副屏，因此需要让Windows认为副屏的触摸在主屏。

设置触摸映射

spicecfg -> Shortcuts -> Tablet PC Settings

串流副屏

需使用显卡欺骗器（也就几块钱），并使用Sunshine+Moonlight。

不支持软件虚拟显示器（软件虚拟显示器不支持独占全屏）。

Sunshine魔改版

支持把触摸映射到主屏和触摸映射旋转（SDVX可用），快说谢谢天线！

安装完成后前往Web后台 -> Configuration -> Input，翻到底部设置触摸映射，然后Save和Apply。

GitHub：https://github.com/JamesLewisLiu/Sunshine/actions/runs/30747911694

Moonlight

官方安卓版不支持多点触控，需使用第三方版本：

  • Moonlight V+
  • 月光·阿西西

其他平台版本应该都支持多点触控。

串流分辨率选择Native即可。

Companion/Substream副屏

不推荐，会使游戏掉帧。

  • SpiceCompanion
    • 已停更
    • https://github.com/spice2x/spicecompanion_archive/releases
  • SpiceCompose
    • 使用Kotlin编写的companion应用
    • https://github.com/C-F0x/SpiceCompose
  • Spice L3
    • 我魔改的SpiceCompanion，翻新了各UI并支持更多平台
    • https://github.com/Longhorn3683/spicecompanion
  • Substream
    • 使用视频串流的全新方案
    • https://github.com/spice2x/substream

BGA

IIDX随时间迭代越来越大，如果硬盘空间吃紧可以考虑删除BGA（仅适用于较新版本）。

视频BGA在data/movie目录，较新的版本的系统BGA在0/1文件夹，较旧的一般用system命名（看视频尺寸也看得出来）。dummy为占位BGA，没有对应BGA就会使用dummy，若没有dummy则一片黑。

layer BGA在data/graphic目录，以歌曲ID命名。

较新版本删除BGA应该没啥问题，20代删除layer BGA进入有Q-pro的歌曲会崩溃（如圣人之塔），更老的版本删除BGA会无法通过自检（HDD DATA ERROR）。

老HDD相关

spice2x目前最低支持到18代，更老的需要使用bemanitools。

Win11 25H2实测可以运行14代及以上版本（更老的还没尝试，12代没运行成功）。

基板大概配置

https://en.namu.wiki/w/KONAMI%20BEMANI%20PC

旧框

  • 1-8代
    • Twinkle（基于PS1）
  • 9-13代
    • Intel Pentium 4 Northwood 2.4GHz
    • NVIDIA GeForce 4 MX440
    • DDR1 PC-2100 256MB
  • 14-19代
    • Intel Pentium 4 Northwood 2.5GHz
    • ATI Radeon X1300
    • DDR1 PC-2700 512MB
  • 20-24代
    • 20代开始支持720P
    • Intel Celeron B810 1.6GHz
    • ATI Radeon E4690
    • DDR3 SODIMM 2GB / 4GB
  • 25-30代
    • 29代开始不再支持480P
    • AMD RX-421BD 2.1(3.4)GHz APU
    • DDR4-2400 4GB
  • 30-至今
    • 30代开始支持1080P
    • Intel Core i5-9400F 2.9GHz/i5-9500E 3.0GHz
    • GeForce GTX 1650 4GB
    • DDR4-2666 8GB / 16GB

新框

LIGHTNING MODEL，俗称雷霆大寺，屏幕尺寸、刷新率，转盘全面升级，米字屏、效果器、数字键盘被副屏取代。

官方介绍：https://p.eagate.573.jp/game/2dx/27/lightning_model/

  • 27-至今
    • Intel Core i5-9400F 2.9GHz
    • GeForce GTX 1650 4GB
    • DDR4-2133/2666 8GB

最新HDD即使使用LDJ模式也很卡

IIDX在30代升级了1080P，配置要求拉高了不少。旧框25代基板由于性能问题，除了打歌都锁30帧，还禁用了摄像头。

要是实在没法稳定60帧，那还是玩29代吧。

31代开始的版本无法运行

31代开始CPU必须支持AVX2，这一代也是抛弃旧框25代基板的一代，没有AVX2最高就只能跑30代了。

自检完就闪退

检查电脑有无D/E/F盘。

应该就2BX有这问题，因为bemanitools没做2BX的E/F盘映射。其他版本可以打E/F盘的patch。

18/19代画面撕裂

不使用专机显卡就会出现画面撕裂。

spice2x已修复这个问题，bemanitools需要把iidxhook的conf中的gfx.diagonal_tearing_fix设置为true。

判定漂移

20代开始用MONITOR CHECK自动调整判定，理论上不存在刷新率相关的判定漂移。更老的版本通过设置DISPLAY TYPE校正判定，一般A为CRT（59.95Hz），B为LCD（60.05Hz），实在不行就试试timebase调整吧。
